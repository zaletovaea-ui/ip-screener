# ip-screener

Технический скринер акций индекса Мосбиржи (дневной таймфрейм): поддержка/сопротивление, EMA200, пробои на объёме, RSI.

- Запуск автоматически пн–пт в 19:10 МСК или вручную: **Actions → «Скан акций» → Run workflow**.
- Результат: `results/latest.md` (таблица) и `results/latest.json` (все данные), история — `results/ГГГГ-ММ-ДД.json`.
- Параметры (2% до уровня, объём ×1.5, RSI 30/70 и т. д.) — в начале `screener.py`, словарь `P`.
- Данные: публичный ISS Мосбиржи. Чтобы ходить через AlgoPack, добавьте секрет `MOEX_TOKEN` (Settings → Secrets → Actions).

Не является индивидуальной инвестиционной рекомендацией.
