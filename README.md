# ip-screener



Не является индивидуальной инвестиционной рекомендацией.

## Сайт и журнал
- Сайт: папка `docs/` (GitHub Pages). Вкладки: подборка дня, журнал сигналов, все сигналы.
- Журнал `docs/data/journal.json`: сигналы из подборки фиксируются по цене закрытия, затем каждый день проверяется, что сработало первым — стоп или цель; через 20 торговых дней сигнал закрывается по рынку.
