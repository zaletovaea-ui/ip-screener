# Помощник «Купонный профит»

Сайт стратегии «Купонный профит»: обзор, портфель с доходностями облигаций, справочник облигаций, календарь выплат, сделки.
Собирается из общего шаблона `tools/strategy_template.html` командой `python3 tools/build_strategies.py`.

Откуда данные:
- состав, статусы, сделки и справочник — Google-таблица «Купонный профит» (листы «Портф для гк», «Сделки по портфелю»,
  «Справочник облигаций в портфеле», только чтение);
- итоги Snowball, ключевая ставка, история стоимости — листы «Сайт · …» этой же таблицы, обновляются задачей раз в 2 дня;
- цены, НКД, доходности, купоны, оферты и курсы валют — Московская биржа (ISS) при открытии страницы.

Скрипт таблицы: `apps-script.gs` (отдельный проект на script.google.com, свой ключ).
Адрес: https://zaletovaea-ui.github.io/ip-screener/profit/
