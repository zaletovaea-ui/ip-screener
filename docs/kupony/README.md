# Помощник «Акции на купоны»

Сайт стратегии «Акции на купоны»: обзор, портфель с доходностями облигаций, календарь выплат, покупки.

Откуда данные:
- состав, статусы и покупки — Google-таблица (листы «Портфель для гк» и «Текущий портфель», только чтение);
- итоги Snowball (полная доходность, полученные выплаты, прогноз, рейтинги), ключевая ставка — листы «Сайт · …»
  этой же таблицы, обновляются задачей по расписанию раз в 2 дня;
- цены, НКД, доходность к погашению/оферте, дюрация, купоны и оферты — Московская биржа (ISS) при открытии страницы.

В репозитории данных портфеля нет: сайт забирает их из таблицы через скрипт Apps Script по секретному ключу (`apps-script.gs`).

Адрес: https://zaletovaea-ui.github.io/ip-screener/kupony/
