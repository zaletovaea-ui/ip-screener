# Помощник «Рост и доход»

Личный сайт для стратегии «Рост и доход»: дашборд портфеля и конструктор постов о сделках.
Главный источник данных — Google-таблица. В репозитории данных портфеля нет: сайт забирает их
из таблицы через скрипт Apps Script по секретному ключу (`apps-script.gs`).

Адрес: https://zaletovaea-ui.github.io/ip-screener/rost/
